# 아기 식탁 🍚

유아식(완료기) 아침·저녁 1주 식단을 자동으로 짜고, 장보기 리스트를 만들어 주는 웹앱이에요.

## 쓰는 법
- **식단**: 🔄 다른 메뉴로 바꾸기, ✋ 목록에서 직접 고르기(📌 고정). [이번 주 새로 짜기]를 눌러도 📌 메뉴는 남아요.
- **장보기**: 이번 주 재료를 코너별로 합산해요. 체크하면 아래로 내려가고, [컬리]를 누르면 컬리 검색 결과가 열려요.
- **설정**: 아기 이름·생일·메시지, 제외 재료(알레르기·안 먹는 것).
- 모든 데이터는 이 폰 브라우저에만 저장돼요.

## 홈 화면에 추가
아이폰의 홈 화면 앱은 Safari와 저장 공간이 따로예요. 그래서 **먼저 홈 화면에 추가하고, 홈 화면 아이콘으로 앱을 연 다음에** 이름·생일·메시지 같은 초기 설정을 해 주세요. (Safari에서 먼저 설정하면 아이콘 앱에는 반영되지 않아요.)

- 아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
- 안드로이드(Chrome): ⋮ 메뉴 → "홈 화면에 추가"

## 레시피 추가·수정
`js/data/recipes.js`에 항목을 추가하고(재료는 `js/data/ingredients.js`에 있어야 해요) `npm test`로 확인한 뒤 다시 올리면 돼요.

## 개발
- 테스트: `npm test` (Node 18+, 설치할 패키지 없음)
- 로컬 실행: `python3 -m http.server 8123` 후 http://localhost:8123

## 안내
레시피는 일반적인 유아식 기준으로 만든 참고용이며 전문가 검수를 거치지 않았어요. 아기의 상태와 소아과 조언에 맞게 조절해 주세요.
